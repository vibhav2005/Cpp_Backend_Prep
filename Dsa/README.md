# DSA Practice

This folder contains Data Structures and Algorithms practice problems implemented in C++.

## Focus

- Arrays and vectors
- Strings and hashing
- Linked list operations
- Sliding window techniques
- Prefix and suffix logic
- Cycle detection
- Hash map based problem solving

## Typical Problems Included

- Two sum
- Longest substring without repeating characters
- Product of array except self
- Maximum subarray sum
- Best time to buy and sell stock
- Maximum consecutive ones
- Palindrome checks
- Linked list reversal and cycle detection

## Purpose

This folder is meant for practicing problem-solving patterns repeatedly and improving confidence in C++ implementations.

## Study Note

The goal is not just to solve once, but to understand the logic clearly and be able to explain the approach and trade-offs.
