# OOP Practice

This folder is dedicated to Object-Oriented Programming practice in C++.

## Topics Covered

- Classes and objects
- Constructors and destructors
- Copy constructors
- Deep copy vs shallow copy
- Encapsulation
- Inheritance
- Polymorphism
- Static members
- Operator overloading
- Reference passing and function behavior

## Examples Included

- Basic class and object exercises
- Student management examples
- Copy constructor demonstrations
- Deep copy implementation
- CRUD-style operations using classes
- Swap by reference example

## Purpose

The aim is to understand how OOP works in real C++ code, not just memorize syntax. These examples help build a stronger mental model for designing object-based programs.

## Revision Tip

Practice these concepts by re-writing examples with different class designs and scenarios until the logic becomes natural.
