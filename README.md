# C++ Revision and Practice Repository

This repository is my personal C++ revision and practice workspace. The goal is to strengthen core concepts, data structures, algorithms, object-oriented programming, and C++ problem-solving through repeated practice and small hands-on projects.

## Purpose

- Revise the fundamentals of C++ regularly
- Practice DSA problems and solution patterns
- Learn and apply OOP concepts
- Build confidence by solving coding problems independently
- Keep a structured repository for self-study and review

## Repository Structure

- [Dsa](Dsa): Data structures and algorithm problem practice
- [Oop](Oop): Object-oriented programming practice and concepts
- [CPP-Projects](CPP-Projects): C++ mini-projects and hands-on exercises
- [DSA-Advance-Concept](DSA-Advance-Concept): advanced DSA and deeper concept work
- [Main.cpp](Main.cpp): general practice or scratch code entry point
- [CMakeLists.txt](CMakeLists.txt): CMake configuration for building the project

- Classes and objects
- Constructors and destructors

- Encapsulation and abstraction

### C++ Revision Topics
- Pointers and references
- Memory management
- STL containers and algorithms
