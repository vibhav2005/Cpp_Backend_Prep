# DSA Advance Concept

This folder is dedicated to my advanced DSA revision plan. The focus is not to rush through topics blindly, but to first understand each concept deeply and then solve at least one problem based on it.

## Learning Method

For every topic in this folder, I will follow this flow:

1. Understand the core concept clearly
2. Learn the intuition behind the approach
3. Study the standard patterns and edge cases
4. Solve one problem on that concept
5. Revise and re-implement it later without notes

## Main Topics

- Backtracking
- Recursion
- Greedy algorithms
- Heap utilities and priority queue patterns
- Dijkstra's algorithm
- A* algorithm
- Graph problems
- Tree problems
- Dynamic programming

## Study Plan

### 1. Backtracking
- Understand state-space exploration
- Learn how recursion builds candidate solutions
- Solve one classic backtracking problem after understanding the pattern

### 2. Recursion
- Focus on base cases, recursion tree, and stack behavior
- Practice problems that involve divide-and-conquer and exploring possibilities
- Solve one problem to strengthen recursion intuition

### 3. Greedy
- Learn when greedy choice is valid
- Study proof of correctness for greedy strategies
- Solve one greedy problem after understanding the decision rule

### 4. Heap Utility
- Understand min-heap and max-heap usage
- Practice priority queue use cases
- Solve one problem using heaps for optimization

### 5. Dijkstra's Algorithm
- Learn shortest path reasoning in weighted graphs
- Understand relaxation and priority queue usage
- Solve one shortest-path problem

### 6. A* Algorithm
- Understand heuristic-based path finding
- Learn the role of g-score, h-score, and f-score
- Solve one pathfinding problem using A*

### 7. Graph Problems
- Focus on traversal, connectivity, shortest paths, and cycle detection
- Solve one graph problem after understanding the graph pattern clearly

### 8. Tree Problems
- Practice recursion on trees
- Understand DFS, BFS, tree traversal, and subtree logic
- Solve one tree-based problem with clean reasoning

### 9. Dynamic Programming
- Learn state definition, transitions, and base conditions
- Solve a few classic DP problems after understanding the recurrence

## Goal

This folder is for deeper revision and stronger problem-solving thinking. The real objective is to understand the idea first and then practice enough to internalize it.

## Note

I will not rush through these topics. I will first understand each concept and then solve one problem per concept to build confidence and clarity.
